# 모바일 청첩장 — 디자인·구현 규칙

이 저장소를 수정할 때 항상 지키는 규칙입니다. 규칙을 바꿔야 할 것 같으면 먼저 사용자에게 확인하세요.

## 폰트
모든 글꼴은 셀프호스팅합니다. 기기 기본 글꼴에 맡기면 PC·일부 안드로이드에서 맑은 고딕이나 사용자가 설정한 글꼴로 바뀌어 촌스럽게 보이기 때문입니다.

| 용도 | 글꼴 | 적용 방법 |
|---|---|---|
| 읽는 글: 섹션 제목·인사말·혼주·커버 일시/장소·예식 일시 문장·예식장명·안내 문구 | Noto Serif KR (명조) | `css/style.css` 상단 그룹 셀렉터에 클래스 추가 → `var(--font-serif)` |
| 성함·큰 숫자 (D-day, 달력 큰 날짜) | Noto Serif KR 600 | 해당 규칙에서 `font-family: var(--font-serif)` |
| 작은 UI 글자: 버튼·계좌번호·연락처·달력 숫자·교통 안내·토스트·라벨 | Pretendard Variable | body 기본값 `var(--font)` — 따로 지정하지 않음 |
| 영문 스크립트 섹션 제목 (Invitation / Location / Date …) | Yellowtail | `.eyebrow` → `var(--font-script)` |
| 커버 손글씨 (We're getting married) | Pinyon Script | 폰트 파일 없음. `scripts/make-handwriting.mjs` 로 SVG 윤곽 생성 |

- 새 글꼴 패밀리를 추가하지 않습니다. 필요해 보이면 비교 시안을 보여주고 사용자에게 묻습니다.
- 외부 CDN 폰트 `<link>` 를 쓰지 않습니다. `node scripts/fetch-fonts.mjs` 로 `assets/fonts/` + `css/fonts.css` 를 생성하고, `css/fonts.css` 는 직접 고치지 않습니다.
- Noto Serif KR 은 400/600 만 있습니다. 명조에 500/700 을 지정하지 마세요 (각각 400/600 으로 보임).
- 명조 본문은 획이 가늘어 `var(--ink)` 색을 유지합니다. 연한 회색(`--ink-faint`)을 명조 본문에 쓰지 마세요.
- 한국어 본문은 최소 14px(0.875rem)입니다. 섹션 제목(`.section-title`) 자간은 0.08em 입니다.
- 인사말(`.greeting-body`)은 320px 화면에서 가장 긴 줄이 한 줄에 들어가야 합니다. 현재 22자 = 260px, 가용 폭 264px. 문구를 바꾸면 다시 측정하세요.

## 색
- `:root` 토큰만 씁니다. 포인트는 버건디 `--accent #701018` (종이 청첩장 색)입니다. 새 색은 토큰으로 추가하고 흰 배경 대비 4.5:1 이상이어야 합니다.
- 라이트 모드 고정입니다(`color-scheme: light`). 다크 모드 스타일은 만들지 않습니다.

## 레이아웃 · 스크롤 (카카오톡 인앱 출렁임 방지)
- 모바일 우선 320~480px, 480px 초과는 가운데 카드입니다. 가로 스크롤이 생기면 안 됩니다.
- `vh`/`svh`/`dvh` 등 뷰포트 높이 단위를 새로 쓰지 않습니다. 인앱 툴바가 나타나고 사라질 때마다 값이 바뀌어 화면이 출렁입니다. 커버 높이는 `index.html <head>` 스크립트가 고정하는 `--cover-h`(px)를 씁니다.
- 애니메이션은 `transform`/`opacity` 만 씁니다. `box-shadow`·`height` 등 레이아웃/페인트 속성은 애니메이션하지 않습니다.
- 지도처럼 터치 스크롤을 가로채는 요소는 탭해야 활성화되는 veil 패턴으로 만듭니다(`#map-tap-veil`).
- 첫 화면 손글씨가 써지는 동안에는 스크롤을 잠급니다(`html.is-locked`). 탭하면 건너뛰고, 7초 뒤에는 잠금이 무조건 풀립니다.
- 모달 대신 인라인 아코디언(`<details class="fold">`)을 씁니다.
- 모션 줄이기(`prefers-reduced-motion`)와 JS 꺼짐 환경에서도 내용이 전부 보여야 합니다(점진적 향상).

## 콘텐츠
- 문구·연락처·계좌·예식 정보는 `js/config.js` 에서만 바꿉니다. 기준은 종이 청첩장(`청첩장.pdf`)입니다.
- 방명록·참석 여부(RSVP)·공유 섹션은 넣지 않습니다 (사용자 결정).
- `assets/img/cover.jpg` 는 웨딩 촬영 전 임시 사진입니다. 공개 저장소라서 올리는 사진·음원은 모두 공개됩니다.

## 검증
- 수정 후 320 / 360 / 375 / 412px 폭에서 확인합니다: 가로 넘침 없음, 의도치 않은 줄바꿈 없음, 콘솔 에러 없음, 폰트 로드(Noto Serif KR · Pretendard Variable · Yellowtail).

## 작업 방식
- 커밋·푸시는 사용자가 요청할 때만 합니다. 브랜치는 `master`, 커밋 작성자는 저장소 로컬 설정(김담영)을 따릅니다.
- 커밋 메시지는 한국어로 변경 요약을 씁니다.
